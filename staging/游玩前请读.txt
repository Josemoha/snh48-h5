〇、v0.13.0 更新内容（成员关系 & 队伍磨合度 · 全线通用）

  · ★新增「队伍磨合度」系统：每支队伍（本部各队 / 预备生 / 各分团）都有
    自己的磨合度（0-100），成员页点击对应队伍标签页即可查看：
      · 初始磨合由队伍成员的【人气·实力均匀度】决定——队伍里成员的人气、
        实力越接近，初始磨合越高；明星成员扎堆、实力两极分化的队伍，
        磨合度天生就低（无实力系统的年代线只按人气均匀度计算）；
      · 队伍连续三个月未发生人员变动（退团除外）后，进入稳定运营期——
        此后每月磨合度 +1：不折腾的队伍，会越处越熟；
      · 任何人员变动——预备生升格、移籍、组阁、新人入队、暂休与归队等——
        都会按现成员重新计算磨合度初始值，并取消稳定加成（重新攒三个月）；
      · 唯一的例外是退团：有人毕业离团不会重算磨合、不清加成——
        送别老队友，不该打乱其余人好不容易磨出来的默契。
  · ★新增「成员关系」系统：成员与成员之间两两有隐性关系值（0-100），
    成员卡上会显示她交情最好的三位队友：
      · 初始值：同队队友 52，其他成员 40——朝夕相处的队友天然更亲；
      · 预备生时期不计成员关系：升格定队之后，才算真正开始同队生涯；
      · 两名成员在同一队伍效力每满半年，关系 +1——同行越久，情谊越深；
      · 若在磨合度过低（<40）的队伍效力，每月每人会随机与一位队友
        关系 -1——磨合崩坏的队伍里，谁的日子都不好过。
  · 关系与磨合度均随跨年继承保留；旧存档读档时自动追补初始化，无需重开。

  · 月支出不再是一个固定数——现在的账本由四项组成，随人头实时变动：

九、游玩方法

  1. 将压缩包解压到任意文件夹（解压后可见 index.html、css、js 三项）
     ★ 重要：请先解压再玩，不要在压缩包里直接双击 index.html——
     很多解压软件会把它解到「临时文件夹」，每次打开都是一个新目录，
     存档会互不相通（表现为：玩过的档「丢了」）。
     建议固定用一个解压目录；更新版本时，用新文件覆盖旧目录内的同名文件，
     不要每次都解压到新文件夹。
  2. 双击 index.html，用浏览器打开即可开始游戏
     （推荐最新版 Chrome / Edge / Firefox；无需安装、无需联网、全程离线可玩。
       ※ 浏览器要求：需较新内核——若打开后出现「浏览器版本过旧」提示，
         请换 Chrome/Edge，或将国产浏览器（360/QQ/搜狗等）切换到「极速模式」；
         不支持 IE 内核。另外请完整解压后再打开，index.html 需与 css、js
         文件夹保持同目录。）
  3. 开局流程：阅读同人声明 → 输入你的名字 → 选择年代线入职
       · 2016「开辟分团」——与AKB48方携手筹办分团，操盘总选举与金曲大赏
       · 2017「本部新章」——2016 通关后在结局页选择「进入下一年」解锁：
         双团开设、实力考核、荣誉殿堂（你的 2016 决策都会带进 2017）
       · 2018「星阵重列」——2017 通关后解锁：全团组阁、预备生汇报公演
         （你的 2016/2017 决策都会带进 2018）
       · 2026「革新征程」——临危受命，执掌末位淘汰与CGT48重建
       · ⚡快速通道（2017/2018/2027）——已通关前作或只想直奔新内容？
         直接从中间年份开局：开局前补选影响当年的关键决策即可
         （代价：无法完整经历此前年份的剧情，选择卡片时会有提示）
  4. 每月 3 点行动点：推进主线 / 走访成员 / 公演经营……
     剧情选项会影响后续走向与结局（S / A / B / C / D 多结局），

十、存档说明与丢失风险（重要，请务必阅读）

  · ★★ 实测结论（请 360 及同类国产浏览器用户特别注意）：
    经实测，360 浏览器以「本地文件」方式打开游戏时，关闭浏览器后
    本地进度【不会被保留】（刷新还在、关闭重开就没，同一路径也一样）。
    QQ、搜狗、2345 等同类国产浏览器也存在同类风险。已实测：
    最新版 Chrome / Edge 官方浏览器打开游戏，进度可正常保留。
    ── 建议：
    ① 首选：使用最新版 Chrome / Edge 官方浏览器游玩，一劳永逸；
    ② 若坚持使用 360 等浏览器：重要进度务必「特殊保存」——
       每次玩完到「系统」页点【保存进度到文件】下载存档文件
       （.sg48save），下次打开后点【从文件恢复进度】选择该文件，
       再「读取存档」继续；也可用【导出存档码】把文字粘贴保存好，
       丢失后【导入存档码】恢复；
    ③ 无论哪种浏览器，都建议关闭「退出时清理浏览数据」类功能。
  · 进度自动保存在「你自己浏览器的存储空间」中（每次行动与月末自动存档），
    系统页内也可随时手动保存 / 读取。
  · 以下情况会导致存档丢失或无法读取，请注意避免：
    1) 清除浏览器缓存 / Cookie / 网站数据（含「一键清理」类操作）
    2) 在浏览器的无痕 / 隐私模式下游玩（关闭窗口存档即消失）
    3) 更换浏览器、更换电脑或设备（存档不跟随文件，也无法跨设备同步）
    4) 手机浏览器自带的「智能清理 / 加速」功能
  · 存档码 / 存档文件在「系统」页与标题页都有入口，跨目录、跨浏览器、
    换电脑通用——重要进度建议每次玩完都备份一次。
  · 存档保存在浏览器里而不是游戏文件夹里，因此移动、复制、删除游戏
    解压目录不会删除存档；但浏览器清理数据会（见上）。
